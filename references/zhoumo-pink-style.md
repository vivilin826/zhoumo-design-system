# 粥沫 Pinky 风格 DNA：极简正文图解

## 默认视觉语法

默认输出是中文文章里的手绘正文图，必须以 `assets/examples/` 的 14 张已确认样图为准：奶油白纸张底、细而略抖的深蓝线稿、粉棕 Pinky、简单的故事道具和克制暖色。

- **留白优先**：至少约一半画面保持干净；背景不画完整房间、风景、墙面装饰或大量家具。
- **关系或场景二选一**：关系类内容先画“输入—处理—输出 / 对比 / 选择 / 转折”；明确动作类内容先画“人物 + 一个主道具 + 一个动作”。不要把场景请求硬改成流程图，也不要把流程图画成生活方式插画。
- **角色是行动主体**：Pinky 通常占画面高度约四分之一到二分之一，作为操作、搬运、连接或观察的人；不要画成占满画面的精修人像。
- **物件克制但有故事性**：保留 1 个主隐喻物件（传送带、桥、漏斗、抽屉、床、工具箱等）与必要卡片、框、箭头或符号；不添加整套室内陈设。

## 线条、质感与比例

- 使用午夜蓝 `#183A70` 的细手绘线条：有轻微不规则感，但清楚、轻盈，不能是粗黑描边。
- 色块是轻薄彩铅/蜡笔颗粒，像纸上手绘；避免高光渲染、厚涂、强阴影、写实材质和 3D 体积。
- Pinky 头略大、五官简洁、四肢线条简约；保持固定人物识别点，但不做精修动漫头像。
- 画面只出现一个明确视觉重心。不要做满屏道具、电影分镜、室内全景或复杂软件界面。

## 固定色板

- 奶油白 `#FFF7E8`：主背景与大面积留白。
- 午夜蓝 `#183A70`：线稿、边框、说明结构和少量中文文字。
- 粉棕 `#D99684`：Pinky 的长卷发。
- 天空蓝 `#4E86C5`：蓝色波点裙。
- 珊瑚红 `#F15A43`：红白波点发夹、流程箭头、强调字。
- 蜜糖黄 `#F6C55F`：星星、重点、少量提亮。
- 嫩黄绿 `#AABF58`：只用于花朵耳环。

颜色关系是“奶油白留白 + 午夜蓝结构 + 粉棕人物识别 + 珊瑚红路径提示”。深蓝只作为线条、局部结构或小面积道具，不能铺成大面积床单、背景墙或深色块；不要使用高饱和渐变。

## 文字规则

- 中文标注是图解的一部分：默认 2—5 处，每处 2—6 个字，写在方框、卡片或箭头附近。
- 除非用户给出必须原样保留的文字，否则只写简短、明确的标签；不加大标题、Logo、水印、长段文案或可读软件界面。
- 使用深蓝说明文字，珊瑚红用于关键提示、箭头或重点词；文字必须服务关系，而非装饰画面。

## 只有明确要求时才切换场景模式

用户明确说“情绪场景、故事插画、封面图、卧室场景、日常 vlog 感或表情包”时，可以用一个有辨识度的主道具承接场景；即使如此，也要保留奶油白、细深蓝线稿、克制色块和 Pinky 的固定识别点，避免补出整间房。

## 禁止

- 不画完整精致房间、满画幅床铺、抱枕、书本堆、窗景或生活方式布景，除非用户明确要求场景图。
- 不做照片感、3D、厚涂、商业扁平矢量、精修动漫、儿童吉祥物或高饱和甜美插画。
- 不使用原版小黑的黑白怪诞语言、黑色实心角色或默认红橙蓝批注体系。
